Edge invariants

  1. Artifact reference、case/sample、reference dictionary、data schema 和 ResultStatus 必须兼容。
  2. Consumer 接收 optional edge 时必须接收 ResultSlot[T]，不得把 None 当状态。
  3. Producer 的 FAILED slot 不进入需要真实 artifact 的 consumer；由 recipe failure policy 决定阻断/跳过。
  4. 所有 edge 在 planning 阶段进行静态类型/Schema 校验，并有 TST-CONTRACT-EDGE-* 测试。
  5. AnnotatedVcf、ExpressionEvidence 等未声明 alias 禁止用于边；需要投影时必须增加显式 transform/API。
  6. 注释变异的可用性和相位证据等级分别验证。必需工件由 recipe 检查 slot 状态、文件与索引；候选/CCF 交接以病例、参考和规范化等位基因为键，坐标约定明确后再比较或连接。

旧流程兼容映射

  • DuplicateMarkedBam 用于 HLA DNA 取证，RecalibratedBam 用于 Mutect2 等调用器。旧 CNVkit 使用重复标记阶段并另接收所选纯度；现有 IF-CNV-001 的 BQSR 请求签名尚不能表达该旧输入，CNVkit 纳入前需单独校验。 旧 CNVkit 输入
  • 旧 NeoFuse 由编排层接收准备后的 RNA reads、适用 Manta SV 与已选 HLA，一次执行并分别收集 IF-RNA-001、IF-FUS-001、IF-NEO-002 结果，绑定同一运行记录。旧 RNA HLA 独立走 reads→IF-HLA-001→IF-HLA-002/003，避免 RNA BAM 与已选 HLA 形成依赖环。RNA 变异读数与 RegTools 还需使用相应注释或相位 VCF。 reads 分流 · NeoFuse · RNA 变异证据 · RegTools
  • 补充 Class II 呈递由兼容适配器读取 IF-HLA-002 的原生 DNA HLA-HD 结果引用，或经等价验证的规范化配对证据，另接收相应长肽与 VCF/事件证据。现有 IF-NEO-001/003 的最终 HLA 字段尚未覆盖这条支路的完整输入。MiXCR 从 IF-READ-001/002 独立启动。 MixMHC2pred · MiXCR
