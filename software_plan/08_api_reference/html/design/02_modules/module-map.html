Design context

模块地图

第一层计算能力与第二层算法单元

第一层功能设计定义 A–G 的交接产物和等价验证范围。第二层算法清单为这七组列出 32 个可独立比较的算法单元。MOD-* 是已有实现设计和接口归属，一个模块可实现多个算法单元，也可支持不同计算能力中的一部分。

第一层计算能力 第二层算法单元 对应实现模块
A 测序数据准备与 DNA 比对 A1 reads 与 QC、A2 比对、A3 重复标记、A4 BQSR 与覆盖 MOD-03、MOD-04
B DNA 变异与注释 B1 体细胞小变异、B2 共识、B3 SV 和候选 indel、B4 胚系、B5 注释、B6 定相 MOD-05、MOD-06
C HLA 分型 C1 DNA 分型、C2 RNA 分型、C3 合并与配对 MOD-07
D 肿瘤特征 D1 CNV/纯度/倍性、D2 单变异 CCF、D3 TMB MOD-08、MOD-09
E RNA 表达与事件 E1 比对、E2 表达、E3 变异级 RNA 支持、E4 融合、E5 异常剪接 MOD-10、MOD-11
F 新抗原候选与呈递预测 F1 常规肽、F2 融合与剪接肽、F3 结合、F4 呈递、F5 补充分数、F6 过滤聚合 MOD-12，MOD-13 承接旧 MixMHC2pred 支线
G 免疫证据分析 G1 参考蛋白匹配、G2 CCF 回填、G3 病例级汇总、G4 候选免疫原性、G5 免疫受体库 MOD-13，G2 依赖 MOD-09 的 CCF 表与回填规则

MOD-01 和 MOD-02 为计算能力提供输入及参考，MOD-14 汇总计算结果和运行状态。这三个支撑模块没有 A1–G5 的算法单元编号。

优先旁路试点

算法单元 候选方法 固定输入和验收
A2 BWA-MEM2 固定 reads、参考和后处理，核对逐条比对及下游变异，再比较耗时和内存
C1 SpecHLA 固定 DNA 及参考，按独立分型真值比较各位点准确率、无结果率和 Class II 配对
F3、F4 NetMHCpan 4.2、NetMHCIIpan 4.3 冻结同一批肽–HLA 对，分别评估 BA 结合亲和力与 EL 呈递，比较覆盖和阈值影响

试点结果与旧方法并行记录。首轮科学对照覆盖配对 WES DNA 到 pVACseq 常规候选全量表和过滤表，首期交付还包含聚合、初版报告和既有运行验收项。 试点验收 · 首轮验收范围

统一模块规则

  • 模块对外只暴露 IF-*；内部实现不可作为跨模块依赖。
  • implementation 加入时必须注册 descriptor、配置、contract test 和一个 recipe。
  • optional 输出使用 ResultEnvelope，不使用空路径。
  • 模块风险与旧行为差异进入 ../07_migration/risk-register.md。
  • 通用质量要求见 ../06_quality/definition-of-done.md。

现有到目标的入口

当前编排集中在 ../../nextNEOpi.nf；资源/参数在 ../../conf/；算法胶水在 ../../bin/；镜像、模型和补丁在 ../../assets/。详细逐项映射见 ../07_migration/current-to-target-mapping.md。
