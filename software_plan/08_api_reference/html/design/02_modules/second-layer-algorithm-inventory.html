Design context

nextNEOpi 第二层算法清单与替换评估

本文沿用第一层的 A～G 功能组，把每组拆到能独立验证的算法或规则。现状以本地提交 9f34698 的代码和配置为准。替代方法根据原始论文或官方文档核对，检索日期为 2026 年 11 月 17 日。首轮按项目现有的配对 Illumina WES DNA → 常规变异候选来排序，RNA、WGS 和其他测序条件另行评估。替代项均是待验证方案，本文没有运行旧流程或新工具。

建议先做三个对照： BWA-MEM2 测比对的输出一致性和性能，SpecHLA 测有独立分型真值时的 HLA 位点准确率，NetMHCpan / NetMHCIIpan 新版在同一批已生成的肽–HLA 对上分别测结合和呈递。DeepSomatic、DeepVariant 和候选免疫原性模型适合并行试跑，依据独立真值和下游候选变化决定是否启用。

现有机器学习功能主要在 B4 的胚系变异过滤、F3/F4 的结合与呈递预测、F5/G4 的免疫原性评分。它们分别需要变异真值、结合或呈递实验数据、以及 T 细胞应答标签。HLA 分型、候选肽枚举、TMB 和 CSiN 可按各自的分型、序列或统计问题验证，也有改进空间。

A2. DNA 比对。 确定 reads 的基因组位置与比对质量 bwa mem 采用种子比对与延伸，后接排序和 GATK MergeBamAlignment，恢复下游使用的 read group 和其他信息。 比对与排序 · 合并 BAM 优先试 BWA-MEM2。 为同一参考重建对应索引，保留其他参数和后处理。逐 reads 比较坐标、CIGAR、MAPQ、flags、RG 与关键标签，进一步核对覆盖和候选，并记录耗时、峰值内存。上游声称对齐输出一致，仍需在本项目参数下确认。 BWA-MEM2 官方仓库

D. 拷贝数、纯度、克隆性与突变负荷

D1. CNV、纯度和倍性。 从深度和等位基因平衡推断肿瘤基因组组成 ASCAT3 根据 LogR/BAF 拟合；Sequenza 根据深度比和等位基因频率估计。主路径选择 ASCAT 或 Sequenza，失败时预测支路可收到默认纯度 0.95。CNVkit 和 Control-FREEC 是分支结果。 ASCAT · Sequenza · 纯度选择 · CNVkit 可对照 FACETS 的等位基因特异 CN，或在目标 panel/WES 上对照 PureCN。验收断点与区段重叠、major/minor CN、LOH、纯度、倍性和回退来源，并记录不同解的置信信息。未经验证先保留 ASCAT/Sequenza 路径。
D2. 单变异 CCF。 结合等位基因读数、区段 CN 和纯度估算携带该变异的癌细胞比例 mkCCF_input.py 组装输入，CCF.R 用二项似然和离散网格估计 CCF 与区间，并输出克隆性判定。实际 CCF 依赖可用的 CN 和纯度，两个估计分支都失败时单独保留缺失状态。 流水线入口 · CCF 计算 先保留公式并回放小粒度真值。用已知纯度、CN 和读数的样例核对极端深度、阈值两侧和无匹配。若需要对变异做亚克隆聚类，可加 PyClone-VI 支线，以簇及其细胞比例另行验证。

F. 新抗原候选构建与呈递预测

这里有三个不同的训练和评估终点。**BA（binding affinity）**估计肽与 HLA 结合强度，通常涉及 IC50 或结合百分位。EL（eluted ligand）或呈递评分用质谱检出的配体等数据学习肽被呈递的可能性。**IM（immunogenicity）**评价肽–HLA 触发特定 T 细胞应答的可能性。每个模型独立存储任务类型、模型版本、原始分数、单位或百分位定义、分数方向和适用范围。

算法单元与问题 当前做法 可选替代与验收
F1. 常规变异到肽。 由突变和转录本得到 WT/MT 序列 pVACseq 消费 VEP VCF、可选定相、HLA 和纯度。有 RNA 时 VCF 还带表达与 RNA 支持。默认 Class I 长度 8–11，Class II 15–25。候选枚举是规则和序列转换。 入口 · 长度配置 先保持枚举和组装规则。比较评分模型时冻结肽–HLA 输入和事件键。若升级 pVACseq，再单独比较转录本版本、突变位置、WT/MT 肽、移码、近邻变异、候选重复数和缺失原因。
F2. 融合和剪接事件到肽。 依据断点或 junction 恢复阅读框并生成候选 NeoFuse 在同一任务输出融合候选，pVACsplice 消费 RegTools junction、注释 VCF、HLA 和纯度。 NeoFuse 候选 · pVACsplice 可用同一份 Arriba 注释事件对比 pVACfuse。剪接可用 splice2neo 作旁路对照。先比事件能否恢复正确转录本、阅读框和肽，再独立评估呈递。现有 pVACsplice 有对错误做降级的路径，验收需区分真正零事件和执行失败。 旧错误处理
F3. BA，Class I/II 结合亲和力。 判断给定肽和 HLA 的结合强度 当前配置包含 Class I 的 NetMHCpan、MHCflurry、MHCnuggetsI，Class II 的 NetMHCIIpan、MHCnuggetsII。NetMHCpan 系列、MHCflurry 和 MHCnuggets 均涉及训练模型。 配置 · 各模型的任务类型 优先对比 NetMHCpan 4.2 和 NetMHCIIpan 4.3 的 BA 输出。 用独立定量结合实验比较 Spearman、对数 IC50 误差和阈值判定，分层报告 HLA、肽长和数据缺口。DTU 新版上线也需要单独核对本地适配、许可证和所用小版本。
F4. EL，Class I/II 呈递。 判断肽被所给 HLA 呈递的可能性 配置包含 Class I 的 NetMHCpanEL、MHCflurryEL，Class II 的 NetMHCIIpanEL。另有 MixMHC2pred 2.0.2.2 支线，它使用 HLA-HD 证据和单独的候选肽构建。 配置 · 呈递算法清单 · 补充呈递路径 对照新版 NetMHCpan/IIpan 的 EL 输出。Class I 可加 MixMHCpred 3.0（2025），Class II 可加 ImmuScope-EL（2025）。用独立免疫肽组质谱的已观测配体评估 AUPRC、Recall@K 和 HLA 覆盖，说明背景或负例构建方式。质谱未检出作为未标注证据处理。
F5. 免疫原性补充分数与加工/稳定性。 提供与结合不同的证据 pVAC 配置已包含 Class I 的 BigMHC_IM 和 DeepImmuno。NetChop 默认关闭，NetMHCstab 默认开启，并依赖对应类别和适用条件。 配置 · 实际参数 已有的 IM 结果按 G 的免疫原性基准一起比较。若新增稳定性或切割模型，分别用对应实验指标验收。旧版 NetMHCstab 适配器会将肽与 HLA 信息发往外部服务，即便结合预测使用本地 IEDB。复现时优先用公开对照数据或已保存的稳定性结果，将联网依赖纳入运行记录。 pVACtools 5.3.0 NetMHCstab 实现
F6. 过滤、聚合与报告字段。 把预测结果按阈值、表达、覆盖和转录本规则整理成候选 pVACseq/pVACsplice 有 standard、relaxed、custom 配置，RNA 文库类型可改变生效的 RNA 筛选条件。旧版 IC50 汇总只使用亲和力估计，综合百分位可能混入多个预测终点的 rank。 过滤配置 · RNA tag 路径 · 旧版聚合实现 先核对实际预测包和模型，再考虑整体升级。pVACtools 7.0.0 提供按结合、呈递、免疫原性划分的输出和规则。按模型保留原始分数，分别验证字段映射、临界值、过滤去留，以及 CSiN 等消费者用到的旧字段。

pVACtools 镜像配置指向 5.3.0。构建文件声明 MHCflurry 2.0.6，BigMHC 和 DeepImmuno 从 Git 安装且未在相应行写明提交号；还应记录实际镜像、IEDB 版本、模型文件哈希和预测器返回的支持清单。现行 pVACtools 文档的 Class I NetMHCpan 执行入口仍列 4.1，因此 4.2 先走直接的本地旁路适配器。Class II 文档有 4.3 参数，也应核对该运行路径实际调用到的版本。 旧镜像配置 · 构建与补丁 · pVACseq 本地版本说明

G. 候选证据、免疫原性与免疫受体库

算法单元与问题 当前做法 可选替代与验收
G1. 参考蛋白匹配。 判断突变肽是否完整出现在参考蛋白中 BLASTP-short 最多返回 5 个比对，解析器保留全长且所有残基一致的命中，并将匹配信息附回候选。 BLAST 参数 · 命中判定 若功能只需精确存在性和匹配蛋白 ID，可用 Aho–Corasick 多模式匹配 在同一蛋白库检索。测试全长、近似、重复命中、边界和旧 BLAST 限制引起的差异。将全库精确索引和旧版截断口径分开报告。
G2. 候选 CCF 回填。 把单变异估计关联到对应候选肽 当前只给 pVACseq 候选追加 CCF。脚本转换坐标后按染色体和位置合并，并启用前向填充。 追加 CCF · 旧合并规则 优先验证精确的病例和等位基因关联，将无匹配保留为缺失。先用相邻变异、同位置不同 ALT、同变异多个肽和输入缺失记录旧输出。变更回填规则需单独比较。
G3. 病例级免疫证据汇总。 聚合常规候选在表达、结合与变异频率上的证据 CSiN 读 pVACseq 全量表，使用百分位、IC50、表达阈值、肿瘤 DNA VAF 和候选负荷计算 Class I/II 和合并分数。属于公式与规则，输入中所用的 VAF 与 D 组 CCF 有不同含义。 输入路由 · 分数公式 · CSiN 论文 先保留公式、旧输入字段和结果语义，验证仅一类 HLA、空候选、缺表达及相同坐标等边界。如果研究目标需要显式克隆结构，再将 NeoPrecis 的病例级景观分析作为独立指标，以相同病例终点比较。 NeoPrecis 论文（2026）
G4. 候选级免疫原性。 对给定候选评估 T 细胞反应的可能性 独立 IGS 分支使用 GBM 梯度提升模型，读取经过滤的常规 Class I 候选，从 WT/MT 肽和突变位置提取特征。业务文档将该模型描述为适用于 8–11 aa 的 SNV 候选，旧 wrapper 实际按 Class I 表和 WT/MT 是否存在选行，模型适用范围应在新接口明确。pVAC 内还有 BigMHC_IM、DeepImmuno。 适用范围 · IGS 输入 · 特征与模型 · GBM 原论文 用现有 GBM、BigMHC_IM 和 DeepImmuno 作基线。Class I 可比较 PRIME 2.0，较新的 NeoPrecis-Immuno（2026） 可按 Class I/II 分层试验，Class II 还可用 ImmuScope-IM。按有实验标注的 T 细胞应答比较 AUPRC、患者内 Precision@K/Recall@K 与覆盖。区分不适用、成功但结果为空和运行失败，测同序列多来源是否重复回填。
G5. BCR/TCR 受体库重建。 从测序 reads 恢复受体链、克隆型与丰度 MiXCR 从 DNA 和 RNA reads 独立运行，按样本角色选 preset，配置的下载版本为 4.7.0。这里做 V(D)J 比对和克隆组装。 版本配置 · MiXCR 输入和 preset bulk RNA 可旁路评估 TRUST4。以链别、CDR3、V/J、克隆集合和丰度为验收项，优先设计与同病例专用受体库测序的对照。保留 DNA 分支单独评估。交接字段参考 AIRR Rearrangement。

替换实验与验收

先做同方法回放，再做新旧方法的性能对照。 回放使用同一份边界输入、参考、模型、过滤规则和版本，验证换编排前后关键实体、过滤去留及状态一致。换模型后允许数值、排序和候选集合变化，是否启用看独立真值、预先约定的指标和下游影响。每次只改一个算法单元，并保存旧结果、新结果和差异。 第一层验证步骤 · 科学等价测试计划

对照实验 固定输入和对照数据 判断依据
1. BWA-MEM2 比对 同一 WES reads、同一参考、相同后处理。至少纳入配对、分片边界和较难比对区域。 核对逐条比对与关键标签变化，向下核对 VCF 与候选。结果满足等价要求后，比较耗时和内存。
2. SpecHLA 分型 冻结 BAM、文库类型与 HLA 字典。有独立高分辨率分型真值的样本按覆盖、位点和等位基因分层。 同时报 two-field 准确率、无结果比例、Class II 配对和实际可评分的 HLA 覆盖。只有覆盖的新等位基因另列，追踪其新增或丢失的候选。
3. BA 与 EL 预测 固定同一批候选肽、序列上下文、HLA 配对和 RNA/纯度。BA 用量化结合实验，EL 用独立质谱配体，现行模型和新版各分数头分别跑。 同时报告共同覆盖集合的表现和全量覆盖率。按 HLA 位点、肽长、少见等位基因及 II 类 α/β 配对分层。实际使用时单独记录不支持、缺上下文和回退。
4. 新变异调用器 固定配对 BAM、WES assay 和参考，以可信区与捕获及可调用区交集评估。SEQC2 HCC1395 可用于兼容性和复核；DeepSomatic 使用过该病例的数据，独立性能验收另留病例。正常胚系用独立 GIAB 数据。 SEQC2 真值 · DeepSomatic 数据与训练 分 SNV/indel、VAF、覆盖和样本类型比较精确率、召回率和 F1。记录新增/丢失的变异、其支持证据、是否经过共识以及影响的候选表行。
5. IM 模型与病例内优先级 采用有独立实验标签的肿瘤新抗原数据，如 TESLA 或另一个未进入所评模型训练的队列。以患者和队列分组，同时检查完全重复肽、相近序列及重叠肽核心。DTU 4.2 部分任务用过 CEDAR 数据，其他模型也要核对训练来源。 TESLA 实验数据 · DTU 训练说明 用病例内 Precision@K/Recall@K、AUPRC 和覆盖率评价，并按患者重采样估计不确定性。实验未测的候选标为未标注。病例级汇总使用病例级终点单独评估。

候选差异报告沿用第一层的身份字段，至少保留病例、事件或规范化等位基因、转录本版本、WT/MT 肽、HLA 或配对、MHC 类别和候选来源。另记录模型与版本、任务类型、输入支持情况、失败原因，以及入选变化来自事件变化、肽变化、HLA 变化还是评分规则变化。评估阈值和可接受的变化在对照前约定，并保留各单位的旧实现作为回退。
