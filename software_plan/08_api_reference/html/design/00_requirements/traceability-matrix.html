变更规则

  1. 新需求必须先分配 ID，并补齐模块、接口和测试。
  2. 新 implementation 不新增功能需求时，至少补充 capability、contract test 和配置追踪。
  3. 科学 policy 变化必须新增或修订 TST-SCI-*。
  4. 删除旧行为前必须在 ../07_migration/compatibility-strategy.md 记录决策。
