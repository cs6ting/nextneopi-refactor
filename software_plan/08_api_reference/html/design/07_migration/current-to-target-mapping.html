Design context

当前代码到目标架构映射

源码映射以旧版提交 9f34698 为准。功能交接见 第一层设计，算法级问题、替代候选及证据见 第二层清单。

主流程与配置

功能组 旧版入口与行为 目标模块或能力
输入与运行 manifest 和参数、检测区间 MOD-01～02、配置 resolver、工具与许可预检
A 测序数据准备与 DNA 比对 BAM 接入、BWA、重复标记、BQSR MOD-03～04，IF-READ/QC/ALN。保留 reads、不同阶段 BAM 及覆盖
B DNA 变异与注释 Mutect2、胚系过滤、共识、VEP、定相 MOD-05～06，IF-VAR/ANN/PHS。输出调用器证据、共识与注释、定相状态和适用的 Manta 证据
C HLA 分型 DNA 取证、RNA reads 分流、HLA-HD、分型合并 MOD-07，IF-HLA。标准分型与各预测器的可用性独立记录，保留 MixMHC2pred 所需分型证据
D 肿瘤特征 ASCAT、纯度回退、CCF、TMB MOD-08～09，IF-CNV/PUR/CCF/TMB。预测所用纯度与 CCF 的可用性独立记录
E RNA 表达与事件 NeoFuse 的 RNA/融合输出、表达及 RNA 读数、RegTools MOD-10～11，IF-RNA/FUS/SPL。与 F 复用旧版 NeoFuse 执行并投影各产物
F 新抗原候选与呈递预测 pVACseq、pVACsplice、MixMHC2pred MOD-12 协调三类候选与呈递，保留 MOD-13 既有补充呈递入口的迁移映射。按任务与 MHC 类别输出
G 免疫证据分析 CCF 回填、BLAST、CSiN、GBM、MiXCR MOD-13，IF-IMM/REP。候选分析与 reads 直连的受体库并行
报告与发布 样本汇总、MultiQC、运行收尾 MOD-14、ArtifactStore、ProvenanceStore

参数、资源与容器配置、部署 profile 和 参考资源 对应目标中的 methods/policies、执行与镜像配置、以及版本化 ReferenceBundle。参见 配置规范。

assets/

*.def/*.yml 迁移为受控镜像构建输入和 image lock；Final_gbm_model.rds/allele lists 进入 versioned model/resource bundle；Frameshift.pm/Wildtype.pm 及 patches 在确认 ownership/许可后进入固定 VEP/工具镜像构建期，禁止运行期 patch；邮件模板归 MOD-14 外围通知 adapter。

判定规则

自研科学转换迁入 domain；第三方命令和原生格式进入 adapter；DAG/资源/retry/publish 进入 infrastructure；未知 ownership 先登记风险，未经许可审查不复制到新发行包。
